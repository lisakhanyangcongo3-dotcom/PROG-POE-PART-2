# PROG-POE-PART-2
Part 1: User AuthenticationRegistration: Captures user details (first name, last name).Validation:Usernames must contain an underscore and be no more than five characters long.   Passwords require high complexity (minimum 8 characters, capital letter, number, and special character).   Cell phone numbers must include an international country code and be no more than ten characters long.   Login: Authenticates returning users against stored credentials.Part 2: Message Management (QuickChat)Drafting: Users define how many messages they wish to enter when the application starts. The system validates message length to ensure it does not exceed 250 characters.   Message Hashing: Autogenerates a unique message hash containing the first two numbers of the message ID, a colon, the message number, and the first and last words of the message in all caps.   Actions:Send: Accumulates the message in the current session.   Store: Saves the full message details locally to a JSON file.   Disregard: Deletes the drafted message and requires a confirmation input.   Session Tracking: The total number of messages is accumulated and displayed once all messages have been sent.   Tech StackLanguage: Java (JDK 11 or higher recommended)Data Storage: JSON (File I/O)Testing: JUnit 5Project StructureChatApp.java: The main execution loop handling the console menus and user input.ChatappLogin.java: Handles user registration, credential validation, and authentication.Message.java: Manages message generation, hashing, formatting, and JSON file storage.
